[ 05 ] — DEPLOY

Two routes in.

ROUTE A — BINARY

Download the build

Open the .dmg from Releases and drag Dynamic Island into Applications. Developer-ID signed and notarized by Apple — no Gatekeeper warnings.

⤓ LATEST RELEASE
ROUTE B — SOURCE

Build it yourself

One script builds the app, installs it to ~/Applications, and registers a LaunchAgent — so it starts at login and self-relaunches if it ever crashes.

zsh — ~/dynamic-island
➜ git clone https://github.com/stoyse/dynamic-island
➜ cd dynamic-island && ./install.sh
# build → install → register LaunchAgent
✓ running on the notch — no dock icon
